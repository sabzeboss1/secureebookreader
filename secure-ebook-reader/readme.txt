Solution d'élite pour la vente et la lecture sécurisée d'ebooks PDF en ligne sur WordPress et WooCommerce sans téléchargement.

== Description ==

Secure Ebook Reader protège vos ebooks et livres numériques PDF contre le piratage, le téléchargement direct et le partage non autorisé.

Fonctionnalités majeures :
* Stockage hermétique hors webroot direct avec triple protection
* Moteur de streaming partiel RFC 7233 (HTTP Range Requests)
* Double filigrane dynamique : overlay DOM et gravure indélébile dans les pixels du canvas PDF.js
* Jetons de lecture éphémères SHA-256 avec révocation immédiate en cas de remboursement WooCommerce
* Lecteur immersif autonome (Thèmes Clair, Sombre, Sépia, Plein Écran, Vignettes)
* Bibliothèque client intégrée dans l'espace Mon Compte WooCommerce
* Tableau de bord d'administration avec KPIs et journal d'audit de sécurité

== Installation ==

1. Téléversez le dossier du plugin dans le répertoire `/wp-content/plugins/` ou utilisez l'archive ZIP via l'admin WordPress.
2. Activez le plugin via l'écran 'Extensions'.
3. Rendez-vous dans le menu 'Secure Ebooks' pour téléverser votre premier livre protégé et régler vos paramètres.
